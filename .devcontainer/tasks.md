# JSON Viewer Development Tasks

## Build Tasks
- **Build (Debug)**: `cargo build`
- **Build (Release)**: `cargo build --release`
- **Run**: `cargo run -- examples/`
- **Test**: `cargo test`

## Code Quality
- **Clippy**: `cargo clippy`
- **Format**: `cargo fmt`
- **Check**: `cargo check`

## Packaging
- **Create .deb Package**: `./build.sh`

## Shortcuts
- Press `Ctrl+Shift+B` to see build tasks
- Press `F5` to start debugging
